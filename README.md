# ZHAYIMUUU

ZHAYIMUUU is a specialized POS and CRM system meticulously designed for the modern imagery artisan. It provides a comprehensive bento-grid interface to manage professional photography workflows, from initial client booking to final delivery.

## 📸 Overview

Modern photographers need more than just a calendar; they need a cohesive system that handles the business of photography so they can focus on their craft. ZHAYIMUUU integrates booking management, financial tracking, client relationships, and production pipelines into a single, high-performance web application.

## ✨ Key Features

-   **Dashboard Hub**: Real-time overview of business health, lifetime earnings, and upcoming schedule.
-   **Intelligent CRM**: Manage client details with integrated invoice generation and payment tracking.
-   **Production Pipeline**: A specialized workflow for tracking post-production, editing, and delivery statuses.
-   **Advanced Financials**: Track income by year and month. Includes a built-in generator for professional payslips.
-   **Booking Calendar**: Dynamic scheduling with quick-action booking management.
-   **PDF Generation**: Seamlessly generate professional Invoices and Payslips directly from the browser.

## 🛠️ Technology Stack

-   **Frontend**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Animation**: [Motion](https://motion.dev/)
-   **Database**: [Firebase Firestore](https://firebase.google.com/docs/firestore)
-   **Authentication**: [Firebase Auth](https://firebase.google.com/docs/auth)
-   **Data Visualization**: [Recharts](https://recharts.org/)
-   **Utilities**: `date-fns`, `jspdf`, `html2canvas`

## 🚀 Getting Started

### Prerequisites

-   Node.js (LTS version recommended)
-   npm or yarn

### Installation

1.  Clone the repository:
    ```bash
    git clone [repository-url]
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Configure your environment:
    -   Copy `.env.example` to `.env`
    -   Provide your Firebase configuration in the platform settings or environment variables.

4.  Start the development server:
    ```bash
    npm run dev
    ```

## 📡 Deployment

The application is built to be deployed on modern cloud platforms like Google Cloud Run or Vercel.

-   **Build command**: `npm run build`
-   **Start command**: `npm run start`
